# Bolli Homebrew

My apps for LG TVs with the webOS Homebrew Channel:

- **Bolli YouTube**: a fast YouTube app with ad block and SponsorBlock ([source](https://github.com/aktiwers/bolli-youtube))
- **Bolli DR**: a fast app for DR's live channels and programmes, in Danish ([bolli-dr](https://github.com/aktiwers/bolli-dr))

## Add it to the Homebrew Channel

1. Open the Homebrew Channel and go to Settings (the gear).
2. Choose **Add repository** and enter:

   ```
   https://aktiwers.github.io/bolli-homebrew/apps.json
   ```

3. Go back. Bolli YouTube and Bolli DR are now in the list, and new versions show up there as updates.
